## The Project.

**A totally new fully responsive, accessible library** with dozens of components to replace the entire front-end UI of a web app that provides patient information to medical practices doing [Value Based Care](https://www.cms.gov/priorities/innovation/key-concepts/value-based-care).

## How might we ...

* Build a system in Figma that exactly models responsive behavior of code.
* Create breakpoints, responsive spacing and flexible grid by hacking Figma tools.
* Allow for fast prototyping for designers and advanced tools for engineers.
___

## Unique Challenges

### No. 1 | Building simple-yet-advanced tools for responsive prototyping

**The goal.** Build a system for designers and engineers to easily solve difficult responsive design problems while allowing both to build significantly faster and better.

**The result.** A unified toolkit that behaves *exactly the same in Figma and in code.* This allows for fully responsive pages in Figma — for free. Prototypes are *engineering-ready blueprints* that match code pixel-for-pixel, function for function.

---

### No. 2 | Hacking Figma tools for uses that were never intended

**The goal.** Use advanced features of Figma tokens and modes to make responsive design simple and intuitive to model in prototypes.

**The result.** A prebuilt responsive infrastructure — breakpoints, flexible grid layouts, components, spacing variables and type styles — can all be built in Figma with live resizing and content reflow. These also allow for a central source of truth and are easier to maintain. The video above shows the breakpoints in action.

---

### No. 3 | Driving adoption and educating users of the system

**The goal.** Ramp up designers and developers on the design system, improve deliverables and speed the engineering process.

**The result.** Launched two initiatives: *Figma Day Camp* and *Design System Office Hours* — focused on education and assistance. Since the system's launch, component use has grown by more than 1,200 percent, from 1,800 to 25,000 + components in use.
